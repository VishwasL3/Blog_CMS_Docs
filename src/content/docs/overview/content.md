### What is Blog - CMS?

Blog CMS is a free, lightweight content management system designed for both developers and writers. It offers:<br>
- For Writers: An intuitive, Editor.js-based interface that allows easy creation and management of blog content.<br>
- For Developers: A simple and secure JSON API for integrating blog content into custom front-end applications.<br>

There are no paywalls or sign-up fees just a fast, no-frills platform that includes:<br>
- User management for content creators<br>
- Draft saving and publishing controls<br>
- API key generation<br>
- Structured JSON endpoints for seamless content consumption<br>

This tool is designed to be minimal yet powerful ideal for side projects, personal blogs, or developer documentation sites.
