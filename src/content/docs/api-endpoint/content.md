- POST:  /api/v1/category/public/get-all – Get all public categories
- POST:  /api/v1/public/blog/get-all – Get API key to retrieve all blogs 
- GET:  /api/v1/public/blog/{Your Blog Id} – Get API key to retrieve a specific blog
